# 学不通 / XueBuTong

Windows 多账号学习任务管理工具，整合 OCS 网课助手与星蝉刷课。

## 主要功能

- 多账号管理、自动登录、账号排序、标签备注及配置导入导出。
- 浏览器与星蝉两种任务模式，按账号选择脚本和启用增强功能。
- 普通题库、大学搜题酱题库、多个 AI 模型及万能题库统一配置，自定义搜题顺序。
- 搜题酱插件与题库共享登录，按学不通账号独立管理多份登录、备注和使用顺序。
- 课程筛选、任务队列、章节开放监控、实时监控与日志查看。
- 后台运行、托盘管理及 GitHub 更新检查。
