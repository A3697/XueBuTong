# 学不通 / XueBuTong

基于 OCS 网课助手的 Windows 账号与任务管理融合层。当前版本 **2.5.10**。

本仓库公开原创融合代码与许可明确的 OCS 部分。原创部分采用 [MIT](LICENSE)，OCS 和其他组件按其各自许可使用，详见 [第三方组件说明](docs/第三方组件说明.md)。

**这是一份公开代码子集，不是包含全部运行组件的完整安装工程。** 星蝉受保护后端、原生前端及派生主要页面未获公开分发授权，因此不在仓库与 Release 中；不提供其解密源码。账号、密钥、浏览器缓存、测试实例和私人二维码也不发布。OCS 聚合编译前端的第三方许可通知尚未逐项核清，该目录也暂不公开；原创界面增强代码保留在 src/fusion。OCS 聚合编译前端的第三方许可通知尚未逐项核清，该目录也暂不公开；原创界面增强代码保留在 src/fusion。OCS 聚合编译前端的第三方许可通知尚未逐项核清，该目录也暂不公开；原创界面增强代码保留在 src/fusion。

## 目录

| 目录 | 用途 |
|---|---|
| `src/fusion` | 账号配置、搜题桥接、监控、浏览器和窗口管理、GitHub 更新。 |
| `src/backend-host` | 星蝉进程宿主、生命周期和协议适配；不包含受保护业务组件。 |
| `src/native-helpers` | Windows 窗口隐藏、恢复所用 C++ 源码。 |
| `src/ocs-app` | 许可明确的 OCS 应用 JavaScript；聚合第三方字体与库的编译前端暂不公开。 |
| `src/star-panel` | 原创的独立布局、筛选、状态和跟随模块；主要派生页面不公开。 |
| `assets` | 原创图标、说明页与许可明确的默认资源。 |
| `build` | 构建工具、安装器和自动测试，未包含私有运行依赖。 |
| `docs`、`LICENSES` | 构建/验收边界和许可说明。 |

## 开发与构建

独立模块可直接阅读、修改和测试，例如安装 Node.js 后运行：

```powershell
node --test build/test_backend_lifecycle.cjs build/test_github_updates.cjs
```

完整离线安装器需要维护者本机匹配的 `XueBuTong_构建依赖`、未公开资源及完整基线清单；仅克隆本仓库不能执行完整重建。`build.ps1` 是完整本地工程使用的固定基线构建入口，不会绕过缺失文件或哈希验证。[源码与构建说明](docs/源码与构建说明.md)描述完整本地工程，[开源与更新](docs/开源与更新.md)说明本仓库的范围。

测试通过不等于所有平台和真实课程均已验收；本轮范围见 [2.5.10 修复验收](docs/2.5.10修复验收.md)。使用服务时应遵守相应平台规则，保留第三方版权、许可和通知。
