# 学不通 2.5.10 修复与验证范围

本版本根据 2.5.9 复测报告修复增强模式退出异常，增加 GitHub 项目与手动更新入口。没有改写已有课程任务、浏览器登录或答题规则。

## 退出修复

- 原生与增强模式均明确使用随包的 `websockets` 适配器，避免自动选择的 Sans-I/O 适配器在连接已经关闭时再次关闭。
- 客户端断开时释放阻塞的 WebSocket 接收/事件任务；接到退出请求立即写入 stopping，终态不被后续启动状态覆盖。
- 主程序等待实际进程退出，将正常清理等待从 8 秒调整为 30 秒；超时强制结束仍需确认进程已退出。停止失败后允许再次停止。
- 异常退出的同一 PID、账号、会话不会再残留 listening；保留后端已经写入的 stopped/failed。
