# 学不通公开源码与更新

项目地址：https://github.com/A3697/XueBuTong

原创融合代码使用 MIT；OCS 网课助手部分保留上游版权和许可。星蝉受保护运行时、原生前端、来源于其前端的页面源码不公开。GitHub Release 同时提供完整安装包与适用于前一兼容版本的增量包；完整包包含星蝉 1.3 运行组件，支持首次安装。私有账号、密钥、浏览器缓存、实例日志和登录凭据均不属于公开内容。

## 从 GitHub 更新

点击主窗口左上角图标，在说明页中点击“检查更新”。发现更新后先下载，再点击“退出并安装”。下载使用 HTTPS 直连 GitHub，校验 GitHub Release 提供的 SHA-256 摘要；不会沿用代理环境变量。正在运行或启动中的账号必须先停止。

程序内更新下载名称为 `XueBuTong-Update-版本-win-x64.exe` 的增量包。它不是首次安装包，不含星蝉原版组件。安装器核对本机版本、保护组件清单和被替换文件；不兼容或本地程序文件已被修改时会停止。此时或首次安装请在 Release 下载 `XueBuTong-版本-win-x64-setup.exe` 完整包。用户数据不被覆盖。

更新前，原程序文件按本次实际替换范围备份在安装目录的 `updates/backup-版本-时间` 中。安装过程中断可先退出所有学不通进程，检查安装结果，再用该备份恢复原程序文件；不要把其他版本的备份混用。Inno Setup 保留并追加原卸载记录，仍可卸载原有全部程序文件。软件不会自动安装更新，不改动官方 OCS 脚本的独立更新管理。

## 公开工程的构建边界

公开仓库可修改原创 Node.js/Python/C#/C++ 模块以及许可明确的 OCS 应用代码。OCS 应用前端包含已编译的 Vue 资源，不能误称为完整上游 TypeScript 工程。

完整离线安装器仍需维护者本机配套的 `XueBuTong_构建依赖` 和未公开的星蝉页面资源。GitHub 仓库不包含这些组件，也不自动下载来源不明的副本；仅克隆仓库不能独立重建完整融合安装包。独立依赖的 LICENSE/NOTICE 必须保留。

公开增量包使用 `build/build_public_update.py` 构建，输入为已审核的当前程序目录及旧版发布清单。`build/public_scope.py` 限定公开内容；新增的非公开组件变更会阻止生成公开更新包，不能通过绕过检查的方式继续打包。

常用原创模块回归测试：

```powershell
node --test build/test_backend_lifecycle.cjs build/test_github_updates.cjs
python -B build/test_native_backend_mode.py
```

上述自动测试不涉及真实账号或课程提交。完整 UI、课程任务、第三方服务额度和长时间运行必须另外验收，不能从单元测试通过推断全部功能已完成实际验证。
