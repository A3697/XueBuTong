同一学不通账号的搜题酱插件与题库通过本机授权通道共享官方认证，多份登录按该学不通账号独立管理。导出只带记录标识、备注、顺序和开关，不带官方登录、昵称/身份缓存、二维码、共享票据或额度状态。界面中的成功搜题次数只统计本机题库入口，不是官方全部已用额度；官方未提供可靠的已用／剩余数值。接口和私密文件范围见 [接口文档](学不通.md)。

公开源码目录与外置二进制依赖分别管理。共享或更换依赖时，保留已知的版权、LICENSE/NOTICE 和来源资料；本交付中的组件清单并不把受保护后端转换成开源模块。准确版本与原始文件身份以 [产品元数据](../fusion-install.json)、[启动器来源绑定](../build/dependency-provenance.json) 和外置依赖清单为准。

## 2.4.7 OCR 运行依赖补齐

从官方 PyPI 分发下载 opencv-python-headless 4.13.0.92、ddddocr 1.6.0 与 NumPy 2.4.4 的 Windows wheel，固定 URL、SHA-256 与大小记录在 `build/ocr-dependency-sources.json`。OpenCV 包含所附的 LICENSE/NOTICE；ddddocr 仅补齐原缺失模型，NumPy 仅补齐同版本缺失 Python 模块，已有二进制不替换。依赖位于同级构建依赖的 `runtime/star-runtime`；不是安装到系统 Python，也不改变平台验证协议。

来源：[OpenCV headless](https://pypi.org/project/opencv-python-headless/)、[ddddocr 官方仓库](https://github.com/sml2h3/ddddocr)、[NumPy](https://pypi.org/project/numpy/)。包内已有许可资料保留。

## 2.5.2 上游更新

网页脚本来自 [OCS 5.4.0](https://github.com/ocsjs/ocsjs/releases/tag/5.4.0)。自动登录配置、中国大学 MOOC 登录实现和智慧树验证码处理取自 [OCS Desktop v3.9.1](https://github.com/ocsjs/ocs-desktop/tree/v3.9.1)。旧平台登录流程保留，验证码阶段调用移植的官方函数；没有升级整个 Electron 桌面底座。精确来源和原始摘要见 `build/automation-upstream.json` 与 `assets/defaults/ocs-script.json`。

以上为 2.5.2 的历史来源记录。2.5.12 当前网页脚本原件已更新为官网 5.4.2，当前摘要与来源以 `assets/defaults/ocs-script.json` 为准；自动登录移植来源与桌面底座未因此整体升级。
