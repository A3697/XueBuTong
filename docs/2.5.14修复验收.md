# 学不通 2.5.14 修复验收

修复判断题答案正文带官方选项编号时的解析错误。正常题干匹配、答案冲突检测、额度优先级、账号隔离与登录共享仍保留。

浏览器模式按当前请求类型记录官方明确耗尽的额度，并按账号顺序切换可用登录；题库独立开关只影响题库入口。异常、验证码、限流或失效登录不会触发连续换号。切换保留网页现有内容，不自动刷新或提交试卷。

导出配置时弹窗选择账号，默认全选并使用主页顺序；仅携带所选账号及其独立配置、队列、窗口大小和排序，软件通用设置保留。取消不会打开文件保存框；没有账号时仍可导出通用设置。

本机真实搜题记录和安装验收在项目修复记录目录保存。真实失败判断题已经复测命中；额度轮换使用官方模块协议及模拟耗尽响应验证，没有实际耗尽用户额度。正式交付前需通过定向回归、完整回归、首次安装、增量升级、卸载与数据保留检查；没有第二台物理设备的验收。
